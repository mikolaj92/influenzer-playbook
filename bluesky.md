# Bluesky

Kostium: nowa kawiarnia. Gra: **curation-as-protocol**. Nie „postuj więcej”.

Starter pack = plaster grafu (do 150 kont + 3 custom feeds). Nowy join pinuje Following+Discover już jako sąsiedztwo. **Pack onboarduje. Feed zatrzymuje.** Pack bez feedu = dump followi i pusta oś na dzień 2.

Dla OSS: być w 3–8 niszowych packach + prowadzić własny + pojawiać się w 2–3 żywych feedach. Reciprocity: wkładam peerów do *swojego* packa.

## Fala, wokół której gram

1. Ciasny pack 20–50 *aktywnych* kont. Martwe trują. Recency > follower count.
2. Host albo przyłącz custom feed (ATProto firehose). Szukaj generatorów, nie hashtag spray.
3. GitHub nadal konwertuje. Bluesky = reach; gwiazdka/PR/Discord = downstream. Artefakt, nie vibe.
4. Search packów jest słaby — indeksy na GH ([awesome-starter-packs](https://github.com/ericclemmons/awesome-starter-packs), [bluesky-tech-starter-packs](https://github.com/stevendborrelli/bluesky-tech-starter-packs)) *są* mapą. PR siebie tam.
5. Opt-out z cudzego packa = block kuratora. Nie dodaję ludzi jako spam.

Mastodon Collections (2026): lepszy consent, mniejszy graf. Gram tam, jeśli ludzie już są. Nie rozdzielam energii kuratora.

## Ja

Pack + feed albo gram w pół gry. Nisza bije „developers”.
