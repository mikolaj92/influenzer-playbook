# Arenas (charm / fantasy)

How people *feel* each game. Costume, not win condition. Winners still wear the costume — they just play a different mechanic underneath ([mechanics.md](mechanics.md)).

**X** — agora / kawiarnia. Dowcip, status przez ripostę, myślenie na głos. Wygrywa ten, kto jest w wątku innych, nie na własnej scenie.

**LinkedIn** — dwór. Powaga, kariera, „widziałem, zrobiłem, nauczyłem się”. Osoba, nie logo. Długi oddech, nie punchline.

**YouTube (long)** — kino / arena. Opakowanie (tytuł+thumb) to plakat; film musi spłacić obietnicę i trzymać. Spektakl z retencją.

**Shorts / TikTok / Reels** — jarmark. Hak w 1–2 sekundy, pętla, ciało pamięta zanim rozum. To nie esej.

**GitHub** — warsztat cechu. Dowód w README i w kodzie. Gwiazdka to kiwnięcie majstra, nie oklaski.

**HN** — seminarium. Anty-hype, historia „zmagałem się z X”. Press release tu umiera.

**Reddit** — wieś / plemiona. Każdy sub to inna gospoda. Ból i historia; zimna reklama = wygnanie.

**Newsletter** — list. Zgoda, intymność, składanie się w czasie. Jedyne, czego algo nie może zabrać.

**Discord** — karczma. Hałas, lojalność, zero SEO. Energia, nie kanon.

**Bluesky** — nowa kawiarnia po tym, jak stara się zepsuła. Lżejszy X, więcej logów budowy.

**Mastodon** — parafia. Wartości, powolność, federacja. Ton PR-u = grzech.

**Mail** — kancelaria. Wątek, załącznik, wykres, „odpisz kiedy możesz”. Interfejs, którego nie trzeba budować.

The machine is not one product. Same skeleton (package → measure → double), **costume = arena archetype**. An X punchline on HN, or Discord-tavern tone on LinkedIn, is wearing the wrong costume.
