# Newsletter

Kostium: list. Gra: **owned list + nawyk + graf recs**. Nie kampania i nie ESP.

Jedyny składający się owned-attention, kiedy algo się kurczy.

1. Zgoda (lista do eksportu) z wynajętej ziemi (GH, X, LI, HN, Notes).
2. Nawyk (imienny editor, jedna obietnica, dzień którego brakuje, gdy skip).
3. Compound przez graf (recs, referral, adjacent swap), nie przez błaganie algo.
4. Dla builderów: **jedno źródło, trzy ramki** — CHANGELOG.md → publiczny `/changelog` → digest w skrzynce. Mail jest dystrybucją, nie kanonem.

400 osób ICP, które odpisują, bije 10k zimnych nazw, które palą domenę.

## Fala, wokół której gram

- Named human. Jedno zdanie obietnicy. Format lock ≥12 numerów zanim kupuję uwagę.
- Cadence = dotrzymany termin. Flagship weekly jeśli daję radę w złym tygodniu; inaczej biweekly. Changelog *strona* może być częsta; changelog *mail* to digest. Cisza, gdy nic user-facing.
- Recs: adjacent, nie klony. Najpierw daję. Boosts/CPA to inna księga niż goodwill.
- Dwie listy, jeśli dwa joby (opinia ≠ product update). Hygiene: sunset nieotwierających. Reply rate > open-rate theater.
- GitHub watchers to *ich* lista, nie moja. README CTA + landing + double opt-in.
