# Discord

Kostium: karczma. Gra: **struktura co-op**, nie puste serwery i nie member count.

Czterech jobów `#general` nie uniesie naraz: install, debug, show work, contribute. Po ~500 `#general` staje się darmowym support deskiem. XP bot tego nie leczy. **Struktura jest grą.**

GitHub zostaje save file (roadmap, merge). Discord = obecność + triage. Win: społeczność odpowiada ≥60% help; TTFR na issue/PR; WAU, nie headcount.

## Fala, wokół której gram

1. **Intent split, nie topic split.** Start here / Get help / Show and tell / Contribute / Lounge. Mało żywych kanałów. Forum `#help` + tagi triage + `resolved`.
2. **Support ma stan zamknięcia.** Nie chat. Archive.
3. **Seed przed publicznym invite.** ~10 builderów zanim otworzę drzwi. Founder presence na 0–200.
4. **GitHub identity.** Linked Roles / contrib; shoutout pierwszego PR w Discordzie.
5. **Jeden rytuał powrotu** (office hours / demo Friday). Ogłoszenie ≠ paste z X; wątek pod spodem; zamknięcie pętli („bug @user w v1.2”).
6. **Discord nie jest Google.** Trwałe Q&A → Discussions.
